# Roost 0.1.40

Coding agents may recover their job-owned Herdr servers within the user's
authorized assignment. Continuing an existing job can restart its unavailable
named server from the saved working directory, then verifies the worker's
identity before sending input. Missing or changed workers still require
inspection; uncertain submissions and approval prompts are not bypassed.

Updates now account for active and resumable coding jobs, including server
recovery in progress. Maintenance continues monitoring existing jobs while
pausing new launches and follow-ups. Complete or stop coding jobs before an
update, including jobs awaiting review or worker input, to preserve sessions
needed for continuation.

Validation covers recovery, worker identity changes, approval blockers,
uncertain submissions, maintenance monitoring, and update interruption guards,
along with the full repository checks.
