# Roost 0.1.39

- Choose Default, Rosé Pine, Carbonfox, or Catppuccin with saved Light, Dark, or
  System appearance. Preview changes before saving.
- Find application settings through Appearance, Notifications, and Account &
  security groups, with search that includes theme names and related terms.
- Build six dashboard chart styles from reusable saved datasets, inspect their
  complete tables, and keep chart colors consistent with the selected theme.
- Choose a catalog-backed model for each automation, or inherit the agent default.
- Use refined mobile Send/Stop controls and a theme-aware return-to-bottom button
  that preserves drafts and resumes following replies.

Database schema 10 preserves existing agents, settings, datasets, and automation
model selections, including upgrades from either schema-9 feature preview.
Tool version 12 refreshes the combined tool inventory while preserving visible
chat history. Disposable capture tooling is excluded from the release.
